# Contributing to WikibaseIntegrator

Thanks for your interest in WikibaseIntegrator!

- **Questions** on how to use the library: see the [documentation](https://lemyst.github.io/WikibaseIntegrator/), or
  ask in the [Q&A discussions](https://github.com/LeMyst/WikibaseIntegrator/discussions/categories/q-a).
- **Bugs**: [open an issue](https://github.com/LeMyst/WikibaseIntegrator/issues/new) with the version of
  WikibaseIntegrator and of Python, a minimal snippet reproducing the problem, and the full error message.
- **Pull requests** are welcome. The
  [Contributing page](https://lemyst.github.io/WikibaseIntegrator/en/latest/guide/contributing.html) of the documentation
  explains how to set up the development environment, run the tests (they run offline) and the lint checks of the CI.
