v0.14.0#

Released on 2026-10-31 - GitHub - PyPI

What’s Changed#

Breaking changes#

  • Replace the archived backoff library with a small retry decorator by @LeMyst in LeMyst/WikibaseIntegrator#1087

  • Split the MediaWiki API retries by cause and lower their default by @LeMyst in LeMyst/WikibaseIntegrator#1095

New features and improvements#

  • Split writes larger than a maximum request size into several edits by @LeMyst in LeMyst/WikibaseIntegrator#1072

  • Add create_redirect() helper for wbcreateredirect by @LeMyst in LeMyst/WikibaseIntegrator#1074

  • Add set_claim() helper for wbsetclaim by @LeMyst in LeMyst/WikibaseIntegrator#1075

  • Add get_available_badges() helper for wbavailablebadges (#309) by @LeMyst in LeMyst/WikibaseIntegrator#1079

  • Retry the read timeouts of read-only MediaWiki API actions by @LeMyst in LeMyst/WikibaseIntegrator#1096

Bug fixes#

  • Keep claims of an unknown datatype instead of failing with IndexError by @LeMyst in LeMyst/WikibaseIntegrator#1081

  • Cancel the removal of a claim when an equal claim is added again by @LeMyst in LeMyst/WikibaseIntegrator#1082

  • Compare qualifiers and references exactly in MERGE_REFS_OR_APPEND by @LeMyst in LeMyst/WikibaseIntegrator#1083

  • Support EntitySchema in fastrun and fix the Property type URI by @LeMyst in LeMyst/WikibaseIntegrator#1084

  • Apply limit_claims and fields_to_update to MediaInfo statements by @LeMyst in LeMyst/WikibaseIntegrator#1085

  • Re-authenticate only once per API call on a lost session by @LeMyst in LeMyst/WikibaseIntegrator#1086

  • Replace instead of duplicating the claims loaded by get_claims() by @LeMyst in LeMyst/WikibaseIntegrator#1088

  • Batch generate_entity_instances() and handle deleted entities by @LeMyst in LeMyst/WikibaseIntegrator#1089

  • Don’t raise KeyError when removing a qualifier of an absent property by @LeMyst in LeMyst/WikibaseIntegrator#1090

  • Let is_bot=False override an api created with is_bot=True by @LeMyst in LeMyst/WikibaseIntegrator#1091

  • Recognize unknown values from any Wikibase in fastrun by @LeMyst in LeMyst/WikibaseIntegrator#1092

  • Use the RDF IRIs of the Commons values in SPARQL queries by @LeMyst in LeMyst/WikibaseIntegrator#1093

  • Don’t multiply the retries of nested retried calls by @LeMyst in LeMyst/WikibaseIntegrator#1094

  • Load the units and precisions of fastrun values lazily by @LeMyst in LeMyst/WikibaseIntegrator#1098

Documentation#

  • Document the ActionIfExists modes of Claims.add() and add_claims() by @LeMyst in LeMyst/WikibaseIntegrator#1073

  • Add a self-hosted coverage badge to the README (#895) by @LeMyst in LeMyst/WikibaseIntegrator#1080

Other changes#

  • Bump version to 0.13.1.dev0 and fix the release upload step by @LeMyst in LeMyst/WikibaseIntegrator#1071

  • Use Trivy’s default DB sources and pin trivy-action by @LeMyst in LeMyst/WikibaseIntegrator#1076
