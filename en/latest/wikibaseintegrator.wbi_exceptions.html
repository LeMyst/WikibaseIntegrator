exception wikibaseintegrator.wbi_exceptions.EmptyValueError[source]

Bases: ValueError

Raised before a write when a claim, a qualifier or a reference has no value, while its snak type states that it has one. A datatype created with None or an empty string as value has no value, and the Wikibase instance would reject it with a less explicit error.

Set a value, or use the WikibaseSnakType.NO_VALUE or WikibaseSnakType.UNKNOWN_VALUE snak type.

exception wikibaseintegrator.wbi_exceptions.MissingExtensionError(error_dict, extension, response=None)[source]

Bases: NonExistentEntityError

Raised when a request needs a MediaWiki extension the Wikibase instance doesn’t provide, e.g. the lexemes of the WikibaseLexeme extension. The extension is either not installed or installed without its repository part.

It inherits from NonExistentEntityError: the requested entity type doesn’t exist on the instance.

exception wikibaseintegrator.wbi_exceptions.UnknownDatatypeError(datatype, supported)[source]

Bases: ValueError

Raised when no data type class handles a datatype, like one added to the Wikibase instance by an extension that WikibaseIntegrator doesn’t support. The message lists the supported datatypes.

Reading an entity doesn’t raise it: a claim of an unknown datatype is kept as a BaseDataType.

exception wikibaseintegrator.wbi_exceptions.WCQSAuthenticationError[source]

Bases: Exception

Raised when the Wikimedia Commons Query Service doesn’t accept the wcqsOauth cookie given to wbi_login.WCQSAuth: it answers with the HTML login page of Wikimedia Commons instead of the query results. The cookie is invalid, or was revoked. It is not retried, as retrying with the same cookie cannot succeed.
